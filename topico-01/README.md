## Comandos executados
- uname -a → mostra informações do sistema
- whoami → mostra o utilizador atual
- pwd → mostra o diretório atual
- hostname → mostra o nome do computador
- date → mostra a data e hora.

## Diferença entre VM, VPS e Cloud
VM: (Virtual Machine) computador virtual local  
VPS:(Virtual Private Server) servidor virtual num datacenter  
Cloud: infraestrutura com vários servidores que oferecem serviços online e escaláveis.
