
# Tópico 1 - Preparação do ambiente Linux

## Ambiente utilizado
Infraestrutura em nuvem (AWS EC2 - Ubuntu Server)

## Objetivo desta atividade
Preparar o ambiente Linux e organizar a primeira evidência técnica.

## Estrutura criada
Foi criada a seguinte estrutura:

linux-seguranca-cloud/
└── topico-01/
    ├── evidencias/
    ├── comandos-topico-01.txt
    └── README.md

## Comandos executados

- whoami - identificar utilizador atual
- pwd - mostrar diretoria atual
- ls -la - listar ficheiros
- hostname - identificar máquina
- cat /etc/os-release - verificar sistema operativo
- uname -a - detalhes do sistema

## Diferença entre VM, VPS e cloud

- VM: máquina virtual local (ex: VirtualBox)
- VPS: servidor virtual remoto
- Cloud: infraestrutura escalável (ex: AWS)
